# Dashboard

The capstone dashboard has six pages, one per Analytics view. The [dashboard build specification](dashboard_spec.md) lists every dataset, visual, filter, tooltip, KPI, footnote, and caveat. Build from it after `04_validation/10_validation_analytics` passes.

The Databricks dashboard and Genie space are not exported here yet.

- Export the dashboard as a file (**Share**, then **Export**) and commit it here, so the repo has the latest version.
- Keep the export in step with the spec. If they disagree, fix one of them before you merge.
- Put screenshots in our Drive folder, not here.
